مشاهده سایتباز کردن GitHub

دسترسی‌های سریع

تنظیمات سایت و Pagesانتشار و وضعیت سایتپوشه عکس‌هاویرایش محتوای اصلی

اضافه کردن عکس واقعی

  1. روی «پوشه عکس‌ها» بزنید.
  2. اگر پوشه خالی است، گزینه Add file و سپس Upload files را بزنید.
  3. عکس‌ها را با نام‌های ساده مثل stage-01.jpg، men-01.jpg، women-01.jpg و decor-01.jpg آپلود کنید.
  4. بعد از آپلود، برای نمایش آنها در گالری باید مسیر عکس در index.html قرار بگیرد. اگر عکس‌ها را همینجا برای من بفرستید، می‌توانم چیدمان گالری را برایتان انجام بدهم.

نکته مهم: آپلود فایل در GitHub عمومی است؛ فقط عکس‌هایی را قرار دهید که اجازه انتشارشان را دارید.
