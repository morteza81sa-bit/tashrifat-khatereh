مشاهده سایتورود به پنل GitHub

عکس‌های واقعی را چطور اضافه کنم؟

  1. روی «ورود به پنل GitHub» بزنید.
  2. وارد پوشه images شوید؛ اگر نبود آن را بسازید.
  3. عکس‌های مراسم را داخل همان پوشه آپلود کنید.
  4. اگر خواستید، عکس‌ها را برای من همینجا هم بفرستید تا چیدمان گالری را برایتان انجام بدهم.

نکته: فعلاً سایت بدون نیاز به دیتابیس کار می‌کند و اطلاعات حساس شما داخل مرورگر ذخیره نمی‌شود.
